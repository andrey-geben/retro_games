Настройки сервера

Адрес и порт, на которых сервер принимает подключения. Применяются при следующем запуске.

Сейчас сервер слушает {{ current_host }}:{{ current_port }}. Сохранённые настройки: {{ settings.host }}:{{ settings.port }}.

Как это работает

  • 0.0.0.0 — принимать подключения со всех интерфейсов: сервер будет доступен в домашней сети по адресу http://{{ lan }}:{{ settings.port }}.
  • 127.0.0.1 — только с этого компьютера.
  • Точный адрес машины — например 192.168.1.73, тогда сервер слушает только его.
  • Порт можно задать и при запуске, минуя эту страницу: python app.py --host 127.0.0.1 --port 8080. Аргументы командной строки важнее сохранённых здесь настроек.
  • Если порт занят другой программой, Flask завершится с ошибкой — выберите другой.

Чтобы применить изменения: остановите сервер (Ctrl+C) и запустите снова. Автоматический перезапуск из веб-интерфейса намеренно не делается — иначе можно потерять доступ к серверу, выбрав недоступный адрес.
