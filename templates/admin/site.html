Примеры SMTP

  • Яндекс: smtp.yandex.ru, порт 465, SSL, логин — полный адрес почты, пароль — «пароль приложения».
  • Mail.ru: smtp.mail.ru, порт 465, SSL.
  • Gmail: smtp.gmail.com, порт 587, STARTTLS, нужен app password.
  • Локальный тест: python -m smtpd -n -c DebuggingServer localhost:1025, затем сервер localhost, порт 1025, без TLS.
