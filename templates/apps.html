Приложения

Как установить ретро-игры на телефон и компьютер: браузер, PWA и APK для Android.

1. Windows — .EXE

Автономный файл: игра, DOSBox Staging и лаунчер внутри. Ничего устанавливать не нужно — запустили двойным кликом и играете.

Скачивается со страницы игры: «Скачать .EXE». Сборка бесплатна.

2. Android / iPhone — установка сайта (PWA)

Сайт можно добавить на главный экран как приложение: иконка, полноэкранный режим, офлайн-кэш оболочки и игр.

  • Android (Chrome): меню ⋮ → «Установить приложение» или «Добавить на главный экран».
  • iPhone (Safari): кнопка «Поделиться» → «На экран Домой».
  • Работает без APK и без магазина приложений.

3. Android — универсальный APK-плеер

Скачать APK-плеер

  • Скачайте файл на телефон и откройте его.
  • Разрешите установку из этого источника (Android спросит один раз).
  • Приложение откроет {{ base_url }}/library — сайт должен быть доступен с телефона.

Если адрес в приложении не тот — задайте «Публичный адрес сайта» в настройках админки.

4. Android — APK на каждую игру

{% if android_ready %}

Как с .EXE, только для Android: отдельный APK, который сразу открывает конкретную игру на весь экран. Кнопка «Скачать APK» есть на странице каждой игры.

  • Сборка идёт на сервере, файл весит десятки килобайт.
  • Нужен доступ к сайту с телефона (тот же публичный адрес).
  • Бесплатно, как и сборка .EXE.
{% else %}

APK на каждую игру собирается тем же Android SDK — пока он не установлен, кнопка недоступна.

{% endif %}

5. iPhone и iPad

Отдельный файл для iOS (`.ipa`) требует Mac, сертификат Apple и подпись — это небыстро и не бесплатно. Зато сайт ставится на домашний экран через Safari (см. пункт 2) и работает как приложение.
